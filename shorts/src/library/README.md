# Shared library

Reusable code-drawn props and sets in the house style (C.ink outlines, flat fills, one soft shade).
When an episode draws something generic (car, door, tree, table, building, pipe, wheel…), put it here
as `props/<Name>.tsx` or `sets/<Name>.tsx` (SVG content centred on (0, 0), size props in rig/world px)
and import it from the episode. Every reused asset makes the next episode faster and more consistent.
